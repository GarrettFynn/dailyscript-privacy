码中纪 · 隐私政策

生效日期：2026-10-18

码中纪是一款本地优先的开发者日记应用。我们坚持：你的日记只属于你。

一、我们收集哪些信息

不收集。码中纪没有账号体系，没有自有服务器，不集成任何统计分析、广告或崩溃收集 SDK。你的全部数据——日记文本、语音、图片、应用配置——仅保存在你设备的本地应用沙盒中。

二、数据何时离开设备

仅在你主动操作且自行配置时：

  1. git 推送：你在「仓库」页填写自己的代码仓库地址并点击推送时，日记内容发送至你配置的服务；应用强制公网地址使用加密连接（HTTPS），局域网明文地址会先向你确认；
  2. WebDAV 备份：你在「同步」页填写自己的 WebDAV 服务器地址并点击备份时，日记与媒体文件发送至你配置的网盘服务（如坚果云等）。

上述传输的目的地、账号与密码均由你本人填写并仅保存在设备加密存储区；码中纪开发者无法接触这些数据。

三、权限用途

权限用途使用时机
网络访问（INTERNET）连接你自己配置的 git 仓库与 WebDAV 网盘，完成推送与备份你主动发起推送/备份时
麦克风（MICROPHONE）在日记中录制语音备忘；录音仅存本机，不上传你在编辑器中点击录音时

四、数据删除

卸载应用即删除设备本地全部数据；你在第三方服务上的备份/推送内容，请在其平台自行管理。
